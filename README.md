## 📋 О проекте / Жоба туралы

**SMART GREENHOUSE 3D** — это веб-симулятор автономной умной теплицы, работающий прямо в браузере как на компьютере, так и на смартфонах. Проект создан на чистом JavaScript и Three.js, полностью автономен и не требует сторонних серверов или баз данных.

### 🌟 Негізгі мүмкіндіктері / Ключевые возможности:
1. **3D Физикалық макет:** Үйшік қаңқасы, қызыл тұғыр, күн панелі, су резервуары, сорғы, STEM бекіткіштер және өсімдіктер (қызанақ пен қияр).
2. **5 Датчик кешені:**
   - 🌡️ **DHT22** — Температура және ауа ылғалдылығы
   - 🪴 **YL-69** — Топырақ ылғалдылығы (автоматты тамшылатып суару)
   - 💡 **BH1750 / LDR** — Жарық датчигі және LED фитожарық панелі
   - 💧 **HC-SR04** — Резервуардағы су деңгейін ультрадыбыстық бақылау
   - 🔬 **MQ-135 + AI** — Өсімдіктердің шіруін (газ бөлінуін) ерте анықтау
3. **📲 Басшының мобильді пульті (Virtual Smartphone):**
   - Шұғыл Push-хабарламалар («Помидорда шіру белгісі табылды!», «Резервуарда су бітті!»)
   - Бір батырмамен қашықтан су құю және өсімдіктерді емдеу
4. **📱 Смартфонға бейімделген интерфейс (Mobile Responsive):**
   - Сенсорлық 3D басқару (сенсормен айналдыру және масштабын өзгерту)
   - 5 бөлімді мобильді мәзір (3D, Телеметрия, Датчиктер, Басқару, Басшы)
5. **📡 100% Офлайн жұмыс және QR-код:**
   - Интернетсіз жергілікті Wi-Fi арқылы кез келген телефоннан ашу

## 🚀 Запуск проекта / Жобаны іске қосу

### Способ 1: GitHub Pages (Онлайн)
1. Сделайте **Fork** или загрузите репозиторий в свой GitHub.
2. Перейдите в **Settings** -> **Pages**.
3. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `/ (root)`
4. Нажмите **Save**. Через минуту ваш сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Способ 2: Офлайн сервер для телефона (Wi-Fi)
1. Запустите файл `START_OFFLINE_СЕРВЕР.bat` (или выполните команду `python server.py`).
2. Сервер автоматически определит ваш локальный IP-адрес Wi-Fi (например, `http://192.168.x.x:8080`) и откроет браузер.
3. Подключите телефон к тому же Wi-Fi (или включите точку доступа на телефоне).
4. Нажмите кнопку **«📱 QR»** в правом верхнем углу сайта и отсканируйте код камерой смартфона.

### Способ 3: Локально без сервера
Просто откройте файл `index.html` двойным кликом в любом браузере (Chrome, Edge, Firefox, Safari).

## 📂 Структура проекта / Жоба құрылымы

```text
├── index.html                  # Главный HTML-документ приложения
├── server.py                   # Автономный локальный HTTP-сервер на Python
├── START_OFFLINE_СЕРВЕР.bat    # Скрипт быстрого запуска для Windows
├── vercel.json                 # Конфигурация для мгновенного деплоя на Vercel
├── .github/
│   └── workflows/
│       └── deploy.yml          # Автоматический деплой на GitHub Pages
├── css/
│   └── style.css               # Стили, Glassmorphism UI и адаптивная мобильная верстка
├── js/
│   ├── main.js                 # Бизнес-логика, телеметрия, пульт директора, QR-код
│   ├── scene.js                # Инициализация сцены Three.js, камеры, света и рендера
│   ├── model.js                # 3D геометрия компонентов теплицы, трубок, датчиков
│   ├── audio.js                # Синтезатор звуков реле, помпы и уведомлений (Web Audio API)
│   ├── hotspots.js             # Интерактивные 3D-точки с описанием датчиков
│   ├── particles.js            # Анимация потоков воды и солнечной энергии
│   └── textures.js             # Процедурные текстуры солнечной панели и грунта
└── lib/
    ├── three.min.js            # Three.js (3D WebGL библиотека)
    ├── OrbitControls.js        # Управление камерой с мыши и сенсорного экрана
    ├── tween.umd.js            # Плавные анимации интерполяции
    └── qrcode.min.js           # Локальный генератор QR-кода
```

## 🛠️ Технологии / Технологиялық стек
- **3D & WebGL:** Three.js r128, OrbitControls
- **Звук:** Web Audio API (полностью процедурный, без внешних аудио-файлов)
- **UI & Адаптивность:** HTML5, CSS3 Glassmorphism, CSS Grid & Flexbox
- **QR-генерация:** qrcode.js (работает 100% офлайн)
- **Сервер:** Python 3 (стандартная библиотека `http.server` + `socket`)
